# Xまとめ 公開データ

[ブラウザで見る](https://takahc.github.io/x-news/)

Xのいいねとタイムラインから拾った投稿を、日本語で短くまとめ、必要なら深掘りした記録です。元の「Xまとめ」ページのデータを、埋め込み画像なしの読みやすいファイルにしたものです。

元投稿の文章・画像URL・投稿時刻は、取得できているものだけ入っています。まとめと深掘りはページに載っていた文章のままです。深掘り中の「（私の推測です）」などの印も、そのまま残しています。

## ファイル

- `data/posts.json` — レコード一覧（新しい順）。UTF-8、整形済み JSON
- `data/users.json` — 投稿者（ハンドル、名前、XのアバターURL）
- `data/posts.csv` — 同じ内容の平たい表（id, datetime, source, author, url, text, summary）

## 件数と時点

- レコード数: 1013
- ユーザー数: 638
- 最新レコード（ダイジェスト追加時刻、日本時間）: 2026-11-21T12:50:00+09:00
- 書き出し元: `new_source43.noprobe.tsx`

`datetime` は、まとめに追加した時刻です。元のX投稿の時刻は `postedAt` にあります。`source` は `likes`（いいね）または `timeline`（タイムライン）です。一部の古いレコードは出典が空です。同じ物語の続きは、元のレコードの `followUps` に入っています。続報の日付はソースに無いため、直前の記録と本文中の投稿時刻より後になるよう補っています。投稿IDが無い続報は、日をまたいだ場合に日付がずれることがあります。

再生成するときは、マージ済みソースを渡して次を実行します。

```
python3 xmatome_export.py SOURCE.tsx OUT_DIR
```
